Tiny Neural Network

A pure Python educational neural network that learns from two numeric inputs, predicts a binary class, and saves or loads its trained weights from the command line.

Run

Clone the repository and start the menu-driven program with python Main.py.

Features

  • Train and test on data.csv
  • Predict from two input values
  • Save and load model weights

Model

The network uses two inputs, one hidden layer with three ReLU neurons, and a sigmoid output for binary classification.
